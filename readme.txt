WooCommerce customization for Bangladesh-focused stores with simple-product size inventory, Bangla content, size charts and streamlined checkout fields.

== Description ==

Features include:

* Custom size inventory for simple products (39–45)
* Required frontend size selection
* Size stored in cart and order metadata
* Size-level stock deduction
* Bangla product details tab
* Per-product size-chart modal
* Bangladesh as the default checkout country
* Simplified/localized checkout fields

This plugin is designed around an opinionated store workflow. Review the configured sizes and checkout assumptions before production use on another store.

== Installation ==

1. Install and activate WooCommerce.
2. Upload this plugin to /wp-content/plugins/.
3. Activate WooCommerce BD Conversion Kit.
4. Configure product-specific fields from the WooCommerce product editor.
